# Agent Memory and Context Manager

Design short and long-term memory strategies that fit an agent's context budget.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Classifies what to remember: ephemeral state, durable knowledge and tool-derived data.
- Designs storage, compression triggers, retrieval signals and staleness handling.
- Delivers a memory table and write/update/forget rules within your context budget.
