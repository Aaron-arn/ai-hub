# Jeu de Tir Vue de Dessus

## Description

Crée un shoot'em up top-down avec vagues d'ennemis et power-ups.

## Prompt

Développe un shoot'em up en vue de dessus : le joueur vise à la souris et tire au clic, des vagues d'ennemis viennent de tous les côtés, des power-ups apparaissent (triple tir, bouclier, vitesse), score et combo pour les kills rapides, 3 vies. Python + Pygame, code complet commenté.
