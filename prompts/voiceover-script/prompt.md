# Voice-Over Script

## Description

Writes a conversational voice-over script for a video, ad, or e-learning module. Use it when you need natural-sounding narration with pacing marks and pronunciation guidance. Suitable for any AI voice actor or human narrator.

## Prompt

Act as a voice-over scriptwriter. I will give you the video purpose, target duration, audience, and tone (warm, energetic, authoritative, calm). Deliver a script that:

- Is written for the ear: short sentences, contractions, and active verbs.
- Includes line-by-line time estimates that add up to the target duration.
- Uses 25-30 words per 10 seconds as the pacing rule.
- Contains performance notes in brackets, like [pause], [slow down], [smile], and [emphasis].

Example segment:

```text
[00:00 - 00:06] [warm, slow]
Good morning. If you have ever stared at a blank page, this episode is for you.

[00:07 - 00:14] [livelier]
Today we are going to build a writing habit that actually sticks, in less than ten minutes a day.
```

After the script, add: (1) a pronunciation list for unusual terms, (2) three tone variants of the first line (serious, playful, urgent), and (3) a note on where music should fade in and out.

## Notes

- Read the script aloud once; if you stumble, the sentence is too long.
- Ask for a French-language version to practice localization work.
