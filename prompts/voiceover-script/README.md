# Voice-Over Script

Writes a natural voice-over script with pacing, performance notes, and tone variants.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Writes ear-first narration with pacing marks.
- Gives per-line time estimates that match your duration.
- Offers tone variants and a pronunciation list.
