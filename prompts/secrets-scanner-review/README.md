# Secrets Scanner Review

Find hardcoded secrets, keys and tokens in code before they leak.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Detects hardcoded secrets, default credentials and sensitive data with location and confidence estimates.
- Assesses the blast radius of each exposure and masks secret values in the report.
- Delivers a remediation plan: rotation, history scrubbing, CI scanners and vault policies.
