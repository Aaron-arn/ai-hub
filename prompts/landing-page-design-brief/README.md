# Landing Page Design Brief

Generates a conversion-focused landing page brief with sections, copy, and hierarchy.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Structures the page section by section for conversion.
- Provides headline, subheadline, and CTA copy variants.
- Includes trust signal placement and A/B test ideas.
