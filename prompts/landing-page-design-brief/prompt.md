# Landing Page Design Brief

## Description

Generates a complete design brief for a conversion-focused landing page: sections, hierarchy, copy blocks, and layout guidance. Use it before wireframing or briefing a designer.

## Prompt

Act as a conversion designer and landing page copywriter. I will give you the product, target customer, and the single action the page must drive (signup, purchase, demo request). Produce a landing page brief with:

1. Page goal and the one metric that defines success.
2. Section-by-section layout (hero, social proof, problem, solution, features, pricing, FAQ, CTA) with the purpose of each section and the exact element order.
3. Copy blocks: headline, subheadline, and CTA button text as ready-to-use options (3 variants each).
4. Visual hierarchy notes: what the eye should see first, second, and third.
5. Trust signals: where to place testimonials, logos, ratings, and guarantees.
6. Mobile priority: which sections must be reordered on small screens.

Use persuasive but honest language, no hype. End with a 3-item A/B test suggestion list. Keep the whole brief under 450 words.

## Notes

- The hero headline should state the outcome, not the product name.
- Test one variable at a time; CTA color and wording are the easiest first tests.
