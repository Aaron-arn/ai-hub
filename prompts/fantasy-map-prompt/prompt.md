# Fantasy Map

## Description

Illustrate an old-style fantasy map with hand-drawn textures.

## Prompt

Illustrate a fantasy map of {LAND_NAME} in an aged parchment style.

Regions to include: {REGION_LIST} (at least 5 named regions)
Key locations: capital city, port, mountain pass, enchanted forest, ruin site - each with a small hand-drawn icon
Decorations: compass rose, sea monsters in the ocean, two decorative banners with region names, border frame with corner ornaments
Textures: parchment aging, ink stains, subtle watercolor washes for terrain (green forests, brown mountains, blue rivers)
Style: hand-drawn ink lines, muted earth tones, slight vignette. Map should look aged and well-traveled.
