# Moteur 3D Minimal

## Description

Créer un mini moteur 3D : caméra, cube texturé et rotation.

## Prompt

En tant que développeur graphique, écris un mini moteur 3D : système de coordonnées, matrice de rotation, projection perspective maison (sans librairie 3D), un cube fil de fer qui tourne en temps réel, et un objet bonus (pyramide). Python avec seulement pygame pour l'affichage. Explique chaque étape mathématique dans les commentaires.
