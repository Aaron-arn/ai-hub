# Cybersigil

## Description

Design a futuristic symbol blending glyphs, circuits and neon glow.

## Prompt

Design a futuristic cybersigil (magical tech symbol) for the concept {CONCEPT}.

Elements to blend:
1. Core glyph: {GLYPH} (e.g., a rune, a letter, a sigil)
2. Circuit traces radiating from the core (thin neon lines)
3. Floating fragments: 3-5 small geometric shards orbiting the sigil
4. Background: dark void with faint grid

Style: dark background #{BG}, neon glow palette {PALETTE} with strong bloom, sharp vector edges, subtle scanline texture. Symmetric composition, centered, the sigil should read as a logo mark even at small size. Include a small "engineering diagram" annotation in one corner.
