# Jeu de la Vie

## Description

Implémente le jeu de la vie de Conway avec motifs célèbres.

## Prompt

Tu es un développeur scientifique. Implémente le Jeu de la Vie de Conway : grille avec cellules vivantes/mortes, règles de naissance et survie, 4 motifs préchargés (planeur, canon à planeurs, grenouille, oscillateur), pas de simulation avec pause et vitesse réglable, compteur de génération. Python ou JavaScript, code commenté avec explication des règles.
