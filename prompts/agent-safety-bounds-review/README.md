# Agent Safety Bounds Review

Review agent designs for permission limits, injection surfaces and runaway risks.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Assesses tool permissions, human oversight, injection surface, runaway risk and auditing.
- Rates each safety area with current state, risk level and concrete mitigations.
- Delivers a prioritized hardening list and a "safe by default" checklist.
