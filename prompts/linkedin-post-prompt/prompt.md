# LinkedIn Post

## Description

Craft engaging LinkedIn posts with hooks and formatting.

## Prompt

Write a LinkedIn post about {TOPIC} for {AUTHOR_PROFILE} (e.g., indie hacker, CTO, designer).

Structure:
1. Hook (first line, max 15 words) - a bold claim, surprising stat, or question
2. Story/insight: 3-5 short paragraphs (max 2 lines each on mobile), one concrete example or number
3. Lesson: a takeaway readers can apply
4. CTA: one question to spark comments

Formatting: line breaks between short paragraphs, 1-2 bold key phrases (use **bold**), a final CTA line. Rules: no hashtag spam (max 3 relevant tags), authentic first-person voice, no hype words ("game-changer", "revolutionary"). Output the post + a hook list of 4 alternatives.
