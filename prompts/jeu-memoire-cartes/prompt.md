# Jeu de Mémoire

## Description

Implémente le jeu de mémoire : retourner des cartes et trouver les paires.

## Prompt

Développe un jeu de mémoire (memory) en JavaScript : grille 4x4 de cartes avec des emojis, clic pour retourner deux cartes, comparaison, paires trouvées qui restent visibles, compteur de coups, minuteur et message de victoire. Animations CSS simples pour le retournement. Fichier HTML autonome, commenté.
