# Compte-Rendu de Réunion

## Description

Transforme des notes de réunion en compte-rendu clair et actionnable.

## Prompt

Tu es un assistant de réunion. À partir des notes brutes que je te donne, produis : 1) l'ordre du jour couvert, 2) les décisions prises (avec qui décide), 3) les actions à faire (qui, quoi, pour quand — sous forme de tableau), 4) les points à trancher plus tard, 5) le résumé en 3 lignes pour ceux qui n'étaient pas là. Reste neutre et factuel, ne suppose rien de ce qui n'est pas dans les notes ; signale les manques.
