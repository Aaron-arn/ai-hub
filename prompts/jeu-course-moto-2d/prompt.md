# Course de Moto 2D

## Description

Développe une course de moto 2D en vue de dessus avec dérapage.

## Prompt

Tu es un développeur de jeux de course. Crée une course de moto 2D vue de dessus : la moto accélère et freine, dérape dans les virages (physique simple), circuit avec lignes d'arrivée et murs, 3 tours, temps par tour et temps total, 2 adversaires contrôlés par l'IA (suivre un itinéraire). Python + Pygame, code complet commenté.
