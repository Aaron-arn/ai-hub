# Twitter Thread

## Description

Turn any topic into a scroll-stopping thread.

## Prompt

Turn this content into a Twitter/X thread: {TOPIC_OR_CONTENT}

Thread rules:
1. Tweet 1: hook - 280 chars, creates curiosity gap, no clickbait
2. 6-9 content tweets: one idea each, scannable (short lines, numbers, emojis as bullets max 2)
3. Each tweet must stand alone AND flow into the next (end with a teaser, start with recap)
4. Tweet N-1: a counterintuitive or memorable point
5. Last tweet: CTA + thread summary line (`For more on {TOPIC}, follow @{HANDLE}`)

Format per tweet: `1/7` numbering or arrows. Mark where to place a screenshot/video. Keep every tweet under 260 chars. Output the full thread ready to paste.
