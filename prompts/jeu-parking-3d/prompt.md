# Jeu de Parking 3D

## Description

Prototype un jeu de stationnement 3D avec manœuvres et chrono.

## Prompt

En tant que développeur de jeux de conduite, crée un prototype de jeu de parking 3D : une voiture contrôlable (marche avant/arrière, braquage, frein), des places de parking matérialisées, la détection de l'arrivée dans la place avec tolérance, un chrono et 3 niveaux de difficulté (espaces de plus en plus petits). Python + Ursina recommandé.
