# Jeu de Course 3D

## Description

Prototype un jeu de course 3D avec circuit, vitesse et chrono.

## Prompt

Tu es développeur de jeux de course. Crée un prototype 3D : une voiture qui avance, accélère et freine, un circuit formé de cubes/portes à traverser, un chronomètre et un classement simple des tours. Python + Ursina recommandé. Code complet, commenté en français, avec instructions de lancement.
