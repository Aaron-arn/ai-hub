# Jeu de Combat 2D

## Description

Développe un fighting game simple : deux combattants et combos basiques.

## Prompt

Développe un jeu de combat 2D : deux combattants sur un ring, déplacements gauche/droite, saut, coup de poing, coup de pied, blocage, barres de vie, round avec timer de 60 secondes, et détection de victoire. Version JavaScript/Canvas ou Python, code commenté en français, contrôles affichés à l'écran.
