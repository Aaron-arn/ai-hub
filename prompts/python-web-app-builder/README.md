# Python Web App Builder

Scaffold a complete FastAPI backend with validation and error handling.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Splits the app into models, routes, deps, and error handling.
- Adds Pydantic validation and a consistent error JSON shape.
- Ships with logging middleware and working /docs.
