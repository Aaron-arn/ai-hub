# Monde Voxel Génératif

## Description

Génère un monde voxel procédural avec montagnes et lacs.

## Prompt

Tu es développeur de mondes procéduraux. Crée un monde voxel génératif : génération de terrain par bruit (perlin ou simplex), couches de blocs (herbe, terre, pierre, eau), montagnes et lacs, spawn du joueur au point le plus haut, et 3 biomes. Python + Ursina recommandé. Explique le bruit dans les commentaires. Code complet.
