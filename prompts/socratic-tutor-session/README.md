# Socratic Tutor Session

Runs a guided tutoring session where questions lead you to the answer yourself.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Asks one guiding question at a time.
- Builds on what you already know.
- Closes with your own summary and a self-test.
