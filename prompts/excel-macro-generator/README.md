# Excel Macro Generator

Generate a ready-to-paste VBA macro for repetitive Excel tasks.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Cleans and normalizes an amount column, highlighting bad values.
- Removes empty rows and formats the sheet automatically.
- Adds totals and averages with formulas below the data.
