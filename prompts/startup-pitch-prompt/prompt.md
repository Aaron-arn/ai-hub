# Startup Pitch

## Description

Craft a pitch deck narrative with investor-ready messaging.

## Prompt

Build the narrative for a {ROUND} pitch deck for {STARTUP}: {IDEA}.

Per slide (max 3 bullet points each, one sentence each):
1. Problem - specific pain, current alternatives' failure
2. Solution - what it is, why now
3. Market - TAM/SAM/SOM numbers + source
4. Product - 3 key features with user value
5. Traction - metrics: {METRICS} (if none, state what to show: beta users, LOIs)
6. Business model - pricing, unit economics
7. Competition - positioning matrix
8. Team - why you're the right founders
9. Financials - 3-year revenue projection logic
10. Ask - amount, use of funds split, milestones

Plus: 30-second elevator pitch and 1-sentence positioning statement. No fluff - every line must answer 'so what?'
