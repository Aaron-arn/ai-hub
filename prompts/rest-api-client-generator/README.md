# REST API Client Generator

Generate a typed JavaScript fetch client from an OpenAPI specification.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Creates a dependency-free class-based client using native fetch.
- Adds typed methods, automatic auth headers, and abort support.
- Throws a structured ApiError for clean error handling.
