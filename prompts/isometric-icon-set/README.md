# Isometric Icon Set

Builds a consistent isometric icon set prompt with a matching style for apps and documents.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Generates a matching set of icons in one generation.
- Keeps one accent color and a single perspective for consistency.
- Lists generated icons and suggests an alternative color scheme.
