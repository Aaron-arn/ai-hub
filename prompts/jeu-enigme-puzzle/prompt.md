# Jeu d'Énigmes

## Description

Construis un puzzle game avec énigmes logiques en escalade de difficulté.

## Prompt

Tu es un game designer de puzzles. Crée un jeu d'énigmes en console Python : 5 énigmes (devinette logique, calcul, déduction, suite logique, énigme spatiale), aide disponible, 3 indices par énigme, score, et progression interdite sans résoudre la précédente. Code complet commenté en français.
