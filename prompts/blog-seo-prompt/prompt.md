# Blog SEO

## Description

Plan a search-optimized blog post with keyword strategy.

## Prompt

Plan a blog post about {TOPIC} for {SITE_DOMAIN}.

Deliverables:
1. **Target keywords**: primary keyword (from me or suggested) + 5 secondary/LSI keywords with search intent (informational/transactional)
2. **Title options**: 5 H1 titles - 2 SEO-heavy, 2 clickbaity-but-honest, 1 plain. Include character counts (<60).
3. **Meta description**: 2 options (<155 chars) with keyword + CTA
4. **Outline**: H2/H3 structure with keyword placement notes, FAQ section with 3 questions (PAA format)
5. **Content rules**: word count range for {TOPIC}, where to place primary keyword (first 100 words, H1, H2, alt text, URL)
6. **Internal linking**: 3 anchor-link suggestions to other posts

Use keyword naturally - no stuffing, no exact-match repetition every paragraph.
