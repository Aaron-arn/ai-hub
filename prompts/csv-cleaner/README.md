# CSV Cleaner

Generate a Python script that cleans, normalizes, and reports on CSV data.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Deduplicates rows and normalizes dates, amounts, and casing.
- Handles multiple date formats and European decimal commas.
- Prints a data-quality report with counts and statistics.
