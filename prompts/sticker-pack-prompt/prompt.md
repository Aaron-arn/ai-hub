# Sticker Pack

## Description

Generate a cohesive set of die-cut stickers in one style.

## Prompt

Create a sticker pack of {THEME} containing 9 stickers.

The stickers: {STICKER_LIST} (describe 9 distinct items/characters)
Cohesion rules:
1. Same art style: {STYLE} (e.g., thick-outline cartoon, kawaii, risograph print)
2. Same palette: {PALETTE} with one accent color used sparingly
3. Same line weight and shading technique
4. Each sticker on its own white die-cut background with white outline border

Presentation: 3x3 grid, slight random rotation of each sticker, visible white die-cut border around every sticker, clean light background.
