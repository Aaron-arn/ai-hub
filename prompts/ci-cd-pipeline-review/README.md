# CI/CD Pipeline Review

Review CI/CD pipelines for secrets handling, test coverage and safe deployments.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Checks secrets handling, test quality, artifact integrity and deployment safety in your pipeline.
- Flags anti-patterns and environment-separation risks that can let broken changes reach production.
- Delivers a prioritized improvement list with implementation steps and the risk of skipping each item.
