# Analyse SWOT d'un Projet

## Description

Rédige une analyse SWOT complète et actionnable.

## Prompt

Tu es un stratège. Pour le projet décrit, produis une analyse SWOT structurée : 5 forces, 5 faiblesses, 5 opportunités, 5 menaces, chacune avec une phrase précise. Ensuite, croise les éléments (SO : forces-opportunités, WO : faiblesses-opportunités, ST, WT) et propose 4 stratégies concrètes issues de ces croisements. Termine par les 3 actions à lancer cette semaine.
