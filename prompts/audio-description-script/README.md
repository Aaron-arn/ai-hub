# Audio Description Script

Writes timecoded audio description narration for videos to make them accessible.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Writes descriptions that fit between dialogue.
- Uses neutral vivid language and verbatim on-screen text.
- Includes timecodes and suggests dialogue cuts.
