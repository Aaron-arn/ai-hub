# Character Sheet

## Description

Design a consistent character across a full turnaround reference sheet.

## Prompt

Design a full character reference sheet for {CHARACTER_DESCRIPTION}.

Layout: 3 views (front, side, back) in a horizontal row, plus:
- 1 portrait close-up with 3 facial expressions (neutral, happy, angry)
- 1 detail panel: hands, feet, costume texture, accessories
- 1 color palette panel with 5 swatches labeled (primary, secondary, accent, skin, trim)

Style: {STYLE} (e.g., Disney-style 3D, anime cel-shaded, painterly realism)
Consistency: keep the exact same proportions, colors and costume in every view. Clean gray studio background, soft shadow.
