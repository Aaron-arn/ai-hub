# SWOT Analysis Framework

## Description

Runs a structured SWOT (Strengths, Weaknesses, Opportunities, Threats) analysis on any business, product, or project. Use it for quarterly planning, before a major decision, or when launching something new. The prompt challenges assumptions and ends with actionable next steps.

## Prompt

You are a strategy consultant who has run SWOT analyses for companies of every size. Perform a SWOT analysis of the following subject.

Subject: [describe the business, product, or project]
Context: [market, competitors, stage of the business, or anything relevant]
Goal of this analysis: [e.g. prepare for launch, decide where to invest, find growth levers]

Work in this order:
1. Ask me up to 5 clarifying questions if critical information is missing. If enough context is given, skip straight to the analysis.
2. Produce the SWOT matrix with 4-6 concrete points per quadrant. Every point must be specific to the subject, not generic business advice. Label each point as internal (S, W) or external (O, T).
3. Rank the single most important item in each quadrant and explain why in 2-3 sentences.
4. Cross-analyze the matrix: list 4 strategic moves, each combining two quadrants (SO: use strength to seize opportunity, WO: fix weakness to capture opportunity, ST: use strength to deflect threat, WT: defend against threat caused by weakness).
5. End with a prioritized action list of 3 things to do this quarter, ordered by impact versus effort.

Be direct and honest. If the subject has a serious weakness or threat, say so clearly instead of softening it.

## Notes

Run the same SWOT twice with different people and compare results. Update the action list quarterly to track whether the strategy worked.
