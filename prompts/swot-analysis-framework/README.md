# SWOT Analysis Framework

Runs a structured SWOT analysis on a business, product or project.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Produces a concrete SWOT matrix with ranked key items per quadrant.
- Combines quadrants into four strategic moves (SO, WO, ST, WT).
- Ends with a prioritized, impact-versus-effort action list.
