# Icône d'Application

## Description

Génère un concept d'icône d'application avec style, couleurs et guide de rendu.

## Prompt

Agis comme un designer d'icônes d'applications. Pour l'application que je décris, définis : le concept visuel central (objet ou symbole), le style (flat, glassmorphism, 3D, skeuomorphisme, néon), la palette de 3 couleurs max, le fond (dégradé, uni, motif), et les détails qui la rendent reconnaissable en petite taille. Donne aussi une description d'image générative de 50 mots prête à être copiée dans un générateur d'images.
