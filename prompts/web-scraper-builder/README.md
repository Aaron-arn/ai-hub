# Web Scraper Builder

Build a polite Python web scraper that exports clean data to CSV.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Scrapes paginated sites with requests and BeautifulSoup.
- Applies delays, retries, and custom headers for polite crawling.
- Normalizes fields and writes a clean UTF-8 CSV.
