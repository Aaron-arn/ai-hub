# Jeu de Détective

## Description

Construis une enquête interactive : suspects, indices et déduction.

## Prompt

Développe un jeu d'enquête en console Python : un crime a eu lieu, 4 suspects avec alibis et mobiles, 8 indices à trouver en explorant des lieux, des dialogues avec questions, un carnet qui note les indices, et un système d'accusation : bonne réponse = victoire, mauvaise = partie perdue. Code complet commenté en français, avec une histoire prête à jouer.
