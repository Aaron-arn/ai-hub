# Study Plan

## Description

Create a personalized study plan from a syllabus and timeline.

## Prompt

Create a study plan to master {TOPIC} in {TIMEFRAME} ({HOURS_PER_WEEK} hours/week) with existing knowledge: {CURRENT_LEVEL}.

Structure:
1. **Milestones**: 3 checkpoints with measurable outcomes (e.g., "can build X without docs")
2. **Weekly schedule**: week-by-week: topic, specific resources/actions, deliverable
3. **Daily routine**: how to split available hours (learning : practice : review ratio)
4. **Practice plan**: exercises/projects per milestone with increasing difficulty
5. **Review system**: spaced repetition intervals for key concepts
6. **Failure checkpoints**: how to detect falling behind and the correction action

Rules: front-load fundamentals, alternate theory and hands-on, include 1 "shake-up" activity per milestone to fight plateau. Realistic hours, not aspirational.
