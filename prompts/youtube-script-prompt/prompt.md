# YouTube Script

## Description

Write a full video script with hook, structure and b-roll cues.

## Prompt

Write a YouTube script for a video about {TOPIC} ({VIDEO_TYPE} e.g., tutorial, review, vlog).

Target: {DURATION} minutes, audience: {AUDIENCE}

Script structure (with timestamps):
1. HOOK (0:00-0:30): pattern interrupt - bold question, crazy claim, or "skip ahead" tease
2. INTRO (0:30-1:00): what you'll get, why you're qualified, roadmap
3. CONTENT (1:00 to 80%): 3-5 beats, each: point -> explain -> example -> transition
4. CLIMAX (80-90%): the "aha" moment or main deliverable
5. OUTRO (90-100%): summary, call to action, subscribe reminder

Format: `[0:00-0:30] SPOKEN: ... (CAMERA: close-up | B-ROLL: screen recording)`. Write conversational spoken English, short sentences, no written-word phrasing.
