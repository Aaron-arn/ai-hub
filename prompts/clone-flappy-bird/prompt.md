# Clone Flappy Bird

## Description

Reproduis Flappy Bird avec physique, tuyaux et score en quelques lignes.

## Prompt

En tant que développeur de jeux, écris un clone de Flappy Bird : oiseau avec gravité et impulsion (clic ou espace), tuyaux qui défilent avec espacement aléatoire, détection de collision, score incrémenté au passage d'un tuyau, et recommencement. Fais-le en JavaScript/Canvas dans une page HTML autonome. Code compact, commenté, prêt à jouer.
