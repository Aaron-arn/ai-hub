# Clone Space Invaders

## Description

Reconstruis Space Invaders : vagues d'aliens, boucliers et vaisseau.

## Prompt

Tu es un développeur de jeux arcade. Reconstruis Space Invaders : vaisseau contrôlé au clavier, aliens en grille qui descendent et s'accélèrent, tirs du joueur et des aliens, boucliers destructibles, bonus de tir, score et 3 vies. Python + Pygame, code complet et commenté.
