# Jeu Plateforme 3D

## Description

Crée un jeu de plateforme 3D simple avec sauts et collectibles.

## Prompt

En tant que développeur de jeux 3D, crée un jeu de plateforme 3D : niveau avec plateformes flottantes, personnage avec déplacement WASD et saut, gravité, détection de chute (respawn), objets à collecter avec compteur, et arrivée sur un drapeau de fin. Utilise Python + Ursina (simple) ou précise l'engine. Code complet commenté.
