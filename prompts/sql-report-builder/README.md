# SQL Report Builder

Translate business questions into correct, runnable SQL report queries.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Builds multi-CTE report queries from plain business questions.
- Uses window functions, date filters, and correct join types.
- Explains each step and flags edge cases the query misses.
