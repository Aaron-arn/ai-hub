# Data Visualization Generator

Generate Python chart scripts that turn raw data into clear visuals.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Builds trend, share, and distribution charts from a CSV.
- Applies consistent, colorblind-safe styling and saved PNGs.
- Handles empty and malformed input with clear errors.
