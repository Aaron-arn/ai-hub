# Revue de Pull Request

## Description

Évalue une pull request comme un reviewer exigeant et bienveillant.

## Prompt

Tu es un reviewer de pull request. Je te donne le contexte (description de la PR) et les changements. Évalue : clarté du titre et de la description, décomposition logique des commits, tests ajoutés et leur qualité, risques de régression, duplication, respect des conventions, et la taille du diff (trop gros ?). Donne un verdict : approve, comment, ou request changes, avec des commentaires précis et constructifs.
