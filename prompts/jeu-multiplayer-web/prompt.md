# Jeu Multijoueur Web

## Description

Construis un jeu multijoueur simple en temps réel avec partage d'écran.

## Prompt

Tu es un développeur temps réel. Crée un jeu multijoueur simple (course de lettres ou jeu du chat-qui-sourit) où deux joueurs partagent le même écran : un contrôle clavier (ZQSD), l'autre flèches, chacun contrôle sa couleur, le premier à atteindre l'objectif gagne. Version local en JavaScript (pas de serveur), avec écran de victoire. Code complet commenté.
