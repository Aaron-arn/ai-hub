# Clone Minecraft Simple

## Description

Construis un jeu de type Minecraft basique : voxels, minage et placement de blocs.

## Prompt

Tu es un développeur de jeux voxel. Écris un jeu type Minecraft minimal mais jouable : monde en blocs (chunk de 16x16x16), rendu simple, caméra à la première personne (souris + WASD), minage et placement de blocs (clic gauche/droit), gravité et collision avec le sol. Utilise Python avec Ursina ou pyglet si possible, sinon précise les dépendances. Code complet et commenté, avec les touches listées au démarrage.
