# JS Package Manager Helper

Diagnose npm and package.json issues and produce safe fix commands.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Explains ERESOLVE conflicts and lockfile drift between machines.
- Detects duplicate-package and build-time resolution issues.
- Recommends safe overrides for vulnerable transitive dependencies.
