# API Endpoint Tester

Generate a full test plan with curl commands for any API endpoint.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Covers happy paths, validation errors, auth failures, and conflicts.
- Provides copy-paste curl commands with status output.
- Includes a CI-ready assertion one-liner and a risk list.
