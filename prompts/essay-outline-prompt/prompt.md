# Essay Outline

## Description

Build a structured essay outline with arguments and evidence.

## Prompt

Create an essay outline for the prompt: {ESSAY_PROMPT}

Word count: {WORD_COUNT} (allocate words per section), academic level: {LEVEL}

Structure:
1. **Thesis statement**: arguable, specific, one sentence - offer 2 versions (balanced / bold)
2. **Intro** (10%): hook, context, thesis placement
3. **Body sections** (80%): 3-4 sections, each with: topic sentence, 2-3 supporting points, counterargument + rebuttal in one section, evidence types to use (statistics, examples, quotes, logic)
4. **Conclusion** (10%): restate thesis (not verbatim), wider implication, no new arguments

Format as a numbered outline with one line per point. For the counterargument section, provide a 3-sentence draft rebuttal.
