# Git Workflow Helper

Turn git messes into safe command sequences with full explanations.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Produces ordered, commented command sequences for messy histories.
- Uses rebase/reset strategies over risky cherry-picks.
- Includes verification and reflog-based recovery commands.
