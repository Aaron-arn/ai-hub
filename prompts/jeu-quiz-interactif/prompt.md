# Jeu Quiz Interactif

## Description

Génère un quiz interactif avec score, timer et questions personnalisées.

## Prompt

Crée un quiz interactif en HTML/JavaScript/CSS : 10 questions avec 4 choix chacun, timer par question (15 secondes), feedback immédiat (bonne/mauvaise réponse), score final avec pourcentage et message selon le résultat, bouton rejouer. Les questions seront fournies dans un tableau JS facile à modifier. Code autonome dans un fichier, commenté en français.
