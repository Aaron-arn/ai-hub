# Jeu de Gestion de Ressources

## Description

Crée un jeu de récolte et gestion : inventaire, craft et objectifs.

## Prompt

Tu es développeur de jeux de survie/gestion. Crée un jeu où le joueur récolte des ressources (bois, pierre, nourriture) sur une carte, les stocke dans un inventaire limité, les craft en objets (outils), et doit atteindre un objectif (construire un abri) avant la nuit. Python + Pygame, code complet et commenté.
