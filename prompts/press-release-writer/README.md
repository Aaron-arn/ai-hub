# Press Release Writer

Writes a journalist-ready press release with headline, quotes and boilerplate.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Produces a full AP-style press release under 500 words.
- Includes headline, subheadline, lead, quotes, and boilerplate.
- Uses placeholders for missing facts so nothing gets invented.
