# Decision Matrix Framework

Scores options against weighted criteria to make complex decisions objectively.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Builds a transparent weighted scoring table for up to 6 options.
- Performs a sensitivity check to see how fragile the winning choice is.
- Produces a recommendation and flags what the matrix cannot capture.
