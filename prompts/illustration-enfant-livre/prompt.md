# Illustration pour Livre Enfant

## Description

Crée des illustrations douces et cohérentes pour un livre jeunesse.

## Prompt

Agis en illustrateur jeunesse. Pour le passage d'histoire que je donne : définis le style (aquarelle douce, collage, couleurs vives), le personnage principal avec ses traits récurrents, la palette adaptée aux enfants, et décris l'illustration pleine page en 80 mots. Ajoute des consignes de cohérence pour que les illustrations suivantes gardent le même personnage.
