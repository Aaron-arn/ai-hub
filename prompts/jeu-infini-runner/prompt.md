# Jeu Infini Runner

## Description

Crée un endless runner avec obstacles aléatoires et vitesse croissante.

## Prompt

Développe un endless runner : personnage qui court automatiquement, saut (espace/clic) avec double saut possible, obstacles générés aléatoirement, vitesse qui augmente avec le score, collision = game over, record local. Version JavaScript/Canvas dans un fichier autonome, commenté en français.
