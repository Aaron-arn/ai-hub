# Clone Snake

## Description

Crée le jeu Snake avec croissance, bonus et collisions.

## Prompt

Développe le jeu Snake : serpent qui se déplace avec les flèches (ou WASD), qui grandit en mangeant des pommes, accélération progressive, mort sur collision avec les murs ou soi-même, score et record en localStorage. Version JavaScript/Canvas dans un fichier HTML autonome, commenté en français.
