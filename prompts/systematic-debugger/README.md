# Systematic Debugger

Debug code methodically: reproduce, isolate, hypothesize, fix and verify with confidence.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Enforces a five-step debugging method: reproduce, isolate, hypothesize, fix, verify.
- Proposes cheap experiments to confirm or discard each hypothesis.
- Focuses on root causes and warns about regression risks before applying fixes.
