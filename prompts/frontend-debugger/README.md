# Frontend Debugger

Diagnose and fix buggy HTML, CSS, and JavaScript snippets with explanations.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Explains root causes for selector, timer, and CSS-cascade bugs.
- Provides corrected, defensive code blocks.
- Lists the DevTools steps to reproduce issues live.
