# Jeu d'Infiltration 2D

## Description

Prototype un jeu de furtivité : ombres, champs de vision et gardes.

## Prompt

En tant que développeur de jeux d'infiltration, crée un prototype 2D : le joueur se déplace en évitant des gardes avec un champ de vision en cône, des zones éclairées où il est repéré, la possibilité de se cacher derrière des objets, l'état d'alerte avec exclamation, et un objectif (porte) à atteindre. Python + Pygame, code commenté.
