# Performance Code Review

Review code for performance issues: complexity, allocations, caching and I/O.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Analyzes algorithmic complexity, allocation pressure, I/O behavior, caching, data access and concurrency.
- Rates issues by impact-per-effort and flags premature optimization.
- Ends with a measurement plan: profiling targets, benchmarks and a performance budget.
