# Flat Design Minimaliste

## Description

Crée des illustrations flat design épurées avec formes simples et couleurs franches.

## Prompt

Agis en designer flat design. Pour le sujet demandé : décris les formes géométriques de base, la palette limitée (2-4 couleurs franches), l'absence de dégradés et d'ombres, les silhouettes épurées et les espaces négatifs. Livre un prompt de 50 mots avec 'flat design', 'minimalist', 'vector illustration'.
