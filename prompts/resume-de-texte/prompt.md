# Résumé de Texte

## Description

Résume n'importe quel texte avec les points clés et les chiffres.

## Prompt

Tu es un spécialiste du résumé. Résume le texte que je fournis en : 1) un résumé de 3 lignes pour décision rapide, 2) les 5 points clés sous forme de liste, 3) les chiffres et données importantes, 4) les implications ou actions à retenir, 5) une question ouverte que le texte laisse en suspens. Adapte le niveau de détail si je te demande une version plus courte ou plus complète. Ne déforme pas le sens, garde la neutralité du texte original.
