# UX Flow Diagram

## Description

Draft a clear user journey map with touchpoints and emotions.

## Prompt

Create a user journey map for {USER_PERSONA} using {PRODUCT}.

Structure the output exactly as:

1. PHASES (6 columns): Discover, Evaluate, Decide, Onboard, Use, Support
2. ACTIONS: what the user does in each phase (bullet list)
3. TOUCHPOINTS: channels used (website, email, app, support chat, word of mouth)
4. EMOTION CURVE: rate -2 to +2 for each phase with one-line reason
5. PAIN POINTS: one per phase with severity rating
6. OPPORTUNITIES: one design opportunity per phase

Format: markdown table for the matrix, then a section per phase with details. Be specific to {PRODUCT}.
