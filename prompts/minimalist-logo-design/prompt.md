# Minimalist Logo Design

## Description

Creates a precise text-to-image prompt for a minimalist logo concept. Use it for brand identity exploration, client moodboards, or personal projects. Works with Midjourney, DALL-E, and Stable Diffusion; the result is a concept, not a final vector file.

## Prompt

Act as a brand designer and logo prompt engineer. I will tell you my brand name, industry, and the feeling I want (e.g. trustworthy, playful, premium). Before writing the prompt, ask me clarifying questions: color preferences, icon vs. wordmark, and square or horizontal format. Then output:

1. A generation prompt in a code block using this structure: logo design for [industry], [icon concept] as a [shape], minimal flat vector style, [1-2 colors], negative space, clean geometric lines, centered composition on a plain [background color], no text, high contrast, professional branding.

Example for a coffee brand:

```text
Minimalist logo design for a specialty coffee brand, a single coffee bean transformed into a rising sun, flat vector style, deep green and cream colors, negative space, clean geometric lines, centered on a plain cream background, no text, high contrast, professional branding
```

2. A short rationale: why this concept works and which symbol reinforces the brand story.
3. Three variations: the icon alone, one with a bold wordmark space left blank, and a monochrome version.

## Notes

- Add "no text" when you plan to place the logo text yourself in a vector editor.
- For a monochrome variant, request "single color black" at the end of the prompt.
