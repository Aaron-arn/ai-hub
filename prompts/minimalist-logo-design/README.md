# Minimalist Logo Design

Creates a precise minimalist logo concept prompt with rationale and variations for any brand.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Produces a structured logo prompt with an icon concept and palette.
- Includes a rationale explaining the symbol's meaning.
- Gives three layout variations including a monochrome version.
