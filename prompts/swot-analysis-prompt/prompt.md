# SWOT Analysis

## Description

Run a structured SWOT analysis for a business or product.

## Prompt

Perform a SWOT analysis for {SUBJECT} (context: {CONTEXT}).

Output:
1. **S - Strengths** (5): internal, verifiable, rank by magnitude
2. **W - Weaknesses** (5): internal, honest, with severity rating
3. **O - Opportunities** (5): external, time-bounded ("within 12 months if...")
4. **T - Threats** (5): external, with likelihood + impact
5. **Strategy matrix** (4 quadrants):
   - S+O: how to exploit strengths to seize opportunities
   - W+O: how to fix weaknesses to capture opportunities
   - S+T: how to use strengths to deflect threats
   - W+T: how to survive weakness+threat combos
6. **Top 3 actions**: priority order with effort/impact estimate

Be concrete - no generic business buzzwords. Mark items you're uncertain about.
