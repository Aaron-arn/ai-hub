# Logo Designer Rapide

## Description

Conçois un logo minimal et mémorable à partir d'une simple description de marque.

## Prompt

Tu es un designer de logos. Pour le nom de marque et le secteur que je te donne, propose 5 concepts de logo : 1) une idée de symbole avec sa signification, 2) un style (minimal, badge, mascotte, monogramme, géométrique), 3) les 2 couleurs principales avec leur justification, 4) le type de police recommandé, 5) où placer le logo (fond clair, foncé, favicon). Reste concis et actionnable pour que je puisse le refaire dans un outil d'IA générative d'images.
