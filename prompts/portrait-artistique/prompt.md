# Portrait Artistique

## Description

Décris un portrait artistique original avec style, éclairage et expression.

## Prompt

En tant qu'artiste portraitiste, transforme la personne ou l'archétype que je décris en portrait artistique. Définis le style (peinture à l'huile, aquarelle, numérique, crayon, pop art), l'éclairage (Rembrandt, néon, lumière du matin), le cadrage (plan serré, buste, trois quarts), l'expression recherchée et l'arrière-plan. Produis une description complète de 80 mots pour un générateur d'images.
