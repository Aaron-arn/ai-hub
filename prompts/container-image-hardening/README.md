# Container Image Hardening

Harden container images against known vulnerabilities and misconfigurations.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Reviews Dockerfiles for base image, user, secret and filesystem issues
- Produces risk-ranked findings with exact fixes
- Ends with a prioritized hardening checklist
