# Cloud Cost Optimizer

Find cloud cost leaks and build a prioritized savings plan with estimates.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Detects idle resources, over-provisioning, storage waste, data-transfer costs and commitment opportunities.
- Estimates monthly savings, effort and risk per finding with a verification method.
- Delivers a prioritized plan and the metrics to track to prevent cost drift.
