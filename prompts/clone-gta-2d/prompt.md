# Clone GTA 2D

## Description

Développe une version 2D très simplifiée de type GTA : ville, véhicules, missions.

## Prompt

Tu es un développeur de jeux open-world 2D. Crée un prototype type GTA en 2D : une ville vue de dessus (routes, bâtiments), un personnage qui marche, vole des voitures (et conduit en suivant la souris), 3 missions simples (livraison, échappement, destruction), police qui poursuit, argent et santé. Écris-le en Python avec Pygame, code complet et commenté en français.
