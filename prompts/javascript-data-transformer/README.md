# JavaScript Data Transformer

Convert messy nested JSON into clean structures with pure functions.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Normalizes inconsistent API payloads into a consistent shape.
- Computes derived fields such as line totals and discounts.
- Provides aggregation helpers with graceful defaults for missing data.
