# Unit Test Writer

Write thorough unit tests with edge cases for your functions and classes.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Covers happy paths, boundary values, and rounding behavior.
- Tests error cases with pytest.raises and match messages.
- Uses parametrize for compact, readable test tables.
