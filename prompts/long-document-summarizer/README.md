# Long Document Summarizer

Summarizes long documents in layers with key points and quotes preserved.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Produces a layered summary: paragraph, key points, numbers, quotes, gaps.
- Separates neutral reporting from a clearly marked verdict section.
- Keeps numbers and quotes traceable to the source document.
