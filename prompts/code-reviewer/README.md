# Code Reviewer

Review code snippets with severity-ranked findings and concrete fixes.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Produces a severity-ranked findings table with fixes.
- Rewrites the code to address critical issues.
- Writes a PR-style summary and suggests regression tests.
