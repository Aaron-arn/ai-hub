# Analyse des Métriques

## Description

Définis et analyse les KPIs d'un projet pour piloter la réussite.

## Prompt

Tu es un analyste produit. Pour le projet décrit, définis : 3 KPIs principaux et 5 secondaires avec formule de calcul et fréquence de mesure, les objectifs chiffrés à 3 mois, les outils de suivi, et un tableau de bord type (les 5 graphiques à mettre en premier). Explique aussi les signaux d'alerte qui doivent déclencher une action.
