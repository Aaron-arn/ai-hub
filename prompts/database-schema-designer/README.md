# Database Schema Designer

Design a normalized SQL schema with DDL and constraints for any domain.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Produces a complete DDL with keys, constraints, and indexes.
- Explains relationships, cardinality, and normalization level.
- Includes seed data for quick smoke testing.
