# Pixel Art Sprite

## Description

Create a game sprite sheet with consistent pixel style.

## Prompt

Create a pixel art sprite sheet for {CHARACTER} in {GAME_STYLE} (e.g., 16-bit JRPG, Game Boy, modern pixel).

Sheet layout (grid, 32x32 pixel sprites):
Row 1: idle 4-frame animation
Row 2: walk cycle 4 frames (left and right)
Row 3: action frames: attack, jump, hurt, victory
Row 4: portrait close-up + 4 emotion portraits

Palette: {PALETTE} max 16 colors. Rules: crisp pixels, no anti-aliasing, consistent light source top-left, readable silhouette, dark outline 1px. Show sprites on a checkerboard background at 200% scale.
