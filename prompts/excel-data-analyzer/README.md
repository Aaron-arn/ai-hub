# Excel Data Analyzer

Turn spreadsheet questions into formulas, PivotTables, and Power Query steps.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Produces SUMIFS, SUMPRODUCT, and array formulas for real data.
- Gives step-by-step PivotTable construction for summaries.
- Covers Power Query loading and type conversion steps.
