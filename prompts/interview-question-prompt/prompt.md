# Interview Question

## Description

Generate role-specific interview questions with answer guidance.

## Prompt

Generate interview questions for {ROLE} ({LEVEL} e.g., senior, junior).

Deliver 12 questions in 3 categories (4 each):
1. **Technical/craft** - role-specific, progression from easy to hard
2. **Behavioral** - use STAR-framework-worthy scenarios (deadline, conflict, failure, ambiguity)
3. **Culture/judgment** - values, priorities, tradeoffs

For each question provide:
- What a strong answer looks like (2-3 bullet criteria)
- Follow-up questions (2)
- Red flags in weak answers

Order questions so difficulty increases. Add a scoring rubric 1-5 with anchors for the behavioral questions.
