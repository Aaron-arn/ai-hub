# Jeu Python avec Pygame

## Description

Génère pas à pas un jeu complet en Python avec Pygame, prêt à exécuter.

## Prompt

Tu es un développeur de jeux Python. Je veux un jeu complet avec Pygame (je choisis le type : snake, casse-briques, plateforme, space invaders). Donne : 1) la structure du code en 3 fichiers (main.py, game.py, entities.py), 2) les constantes (taille écran, couleurs, FPS), 3) la boucle de jeu, 4) la gestion des entrées clavier, 5) les collisions, 6) le score et le game over. Écris le code complet, fonctionnel et commenté en français, en t'assurant que pygame est la seule dépendance.
