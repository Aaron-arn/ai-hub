# Simulation de Ville

## Description

Crée une mini simulation de ville : routes, bâtiments et croissance.

## Prompt

Tu es développeur de jeux de gestion. Crée une mini simulation de ville : une grille où le joueur place des routes et des bâtiments (maison, commerce, usine), la population augmente avec le logement, l'argent diminue avec les services et augmente avec les commerces, et un affichage des statistiques. Python + Pygame, avec sauvegarde de la carte en JSON. Code complet.
