# Translation Proofreader

Reviews translated text for accuracy, natural tone and terminology consistency.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Scores the translation and lists every error with a corrected version.
- Checks terminology consistency and cultural suitability.
- Returns a fully corrected translation ready to use.
