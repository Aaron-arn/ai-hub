# Bannière Web

## Description

Crée le concept d'une bannière web attractive : hiérarchie, couleurs et texte.

## Prompt

Tu es un designer web. Je vais te donner le produit et le message de la bannière. Propose : la structure de la composition (texte à gauche, produit au centre, etc.), le fond (photo, dégradé, motif géométrique), les 2 couleurs d'accent, la typographie (titre + sous-titre) et un bouton d'action avec son libellé. Donne enfin un prompt d'image générative détaillé de 60 mots pour produire le visuel.
