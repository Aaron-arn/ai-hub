# Regex Pattern Builder

Craft explained, tested regex patterns for extraction and validation.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Builds engine-specific regexes with named capture groups.
- Explains every token so you can maintain the pattern.
- Verifies matches against positive and negative samples.
