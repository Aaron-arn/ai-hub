# Jeu Plateforme JavaScript

## Description

Crée un jeu de plateforme en JavaScript avec niveaux et pièces.

## Prompt

En tant que développeur de jeux web, crée un jeu de plateforme en HTML/JavaScript/Canvas : personnage qui court et saute (flèches ou ZQSD), gravité, collisions avec les plateformes, pièces à collecter, ennemis simples, 3 niveaux avec difficulté croissante, et un système de vie. Fichier HTML autonome, code commenté en français.
