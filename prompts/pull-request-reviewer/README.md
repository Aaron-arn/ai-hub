# Pull Request Reviewer

Review pull requests for correctness, security, performance, tests and readability.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Reviews diffs across five dimensions: correctness, security, performance, tests, style.
- Produces numbered comments with file locations, severities and concrete suggestions.
- Ends with a clear verdict: approve, request changes, or approve with comments.
