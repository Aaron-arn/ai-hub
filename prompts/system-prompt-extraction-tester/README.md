# System Prompt Extraction Tester

Evaluate how easily a system prompt can be extracted and how to defend it.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Runs authorized extraction techniques: direct requests, role-play pretexts, output tricks and format abuse.
- Records success or refusal per technique and rates the model's resistance.
- Delivers anti-extraction defenses: no-disclosure rules, instruction-quoting filters and training updates.
