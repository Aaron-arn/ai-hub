# Logo Moodboard

## Description

Explore visual directions for a brand with a 2x2 logo style moodboard.

## Prompt

Create a 2x2 moodboard exploring logo directions for {BRAND}, a company in {INDUSTRY}.

Tile 1: Minimalist mark - single geometric symbol, black on white
Tile 2: Mascot - friendly character, flat vector style
Tile 3: Typographic - bold wordmark with custom lettering
Tile 4: Badge/emblem - circular badge, vintage feel

Each tile must include: the concept name, a color palette swatch of 3 colors, and 3 words describing the personality. Grid layout with thin white gutters, clean studio background.
