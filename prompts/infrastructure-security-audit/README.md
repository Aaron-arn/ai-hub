# Infrastructure Security Audit

Audit infrastructure for exposure, weak access control and missing encryption.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Audits exposure, access control, encryption, data protection, monitoring, maintenance and recovery.
- Produces a maturity assessment per area with severity-ranked findings and remediation.
- Delivers a 30-60-90 day action plan referencing your actual resources.
