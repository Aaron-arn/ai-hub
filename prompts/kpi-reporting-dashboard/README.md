# KPI Reporting Dashboard Builder

Designs a KPI dashboard with metrics, targets and reporting cadence.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Chooses a North Star metric and a 3-level hierarchy of supporting metrics.
- Defines formulas, targets, and review cadence for every metric.
- Produces a dashboard layout and flags metrics that can be gamed.
