# Frontend Component Builder

Build an accessible, reusable React component with props and keyboard support.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Creates a controlled React component with a clear props API.
- Implements full keyboard navigation and focus management.
- Adds ARIA roles and attributes for screen-reader compatibility.
