# Prompt Engineering Tutor

Turn vague requests into structured, high-performing LLM prompts.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Rewrites tasks into role, rules, and output-format sections.
- Adds worked examples and failure-mode protections.
- Explains why each element improves output quality.
