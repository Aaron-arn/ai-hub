# Trouver un Partenaire d'Affaires

## Description

Définis le profil du partenaire idéal et le plan pour le trouver.

## Prompt

Tu es un expert en alliances. Pour mon projet (et mes compétences), définis : le profil du partenaire idéal (compétences complémentaires, valeurs, contribution, rémunération), les signaux d'alerte (compatibilité, motivation), les endroits où le rencontrer (communautés, événements, réseaux), les questions à poser lors de la première rencontre, et un modèle de pacte d'associés simple à faire valider par un avocat. Donne aussi 3 exemples de répartition des parts équitables.
