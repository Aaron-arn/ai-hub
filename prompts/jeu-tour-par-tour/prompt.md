# Jeu de Combat Tour par Tour

## Description

Crée un système de combat au tour par tour complet avec types d'attaques.

## Prompt

Tu es un game designer. Crée un combat au tour par tour entre le héros et un monstre : 4 actions (attaque, attaque spéciale, défense, potion), dégâts avec variance aléatoire, défense réduisant les dégâts, affichage des barres de vie, tours alternés avec temps d'attente, victoire/défaite avec message. Version Python console ou JavaScript, code commenté.
