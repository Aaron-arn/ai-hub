# SQL Query Optimizer

Rewrite slow SQL queries and recommend indexes for faster execution.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Identifies query problems such as bad joins, casts, and missing predicates.
- Rewrites the query to an equivalent, faster form.
- Recommends exact index statements and explains the execution plan impact.
