# Python CLI Scaffolder

Generate a complete, production-ready Python CLI tool skeleton with argparse.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Creates an argparse-based entry point with flags, version, and logging.
- Separates business logic into pure, testable functions.
- Includes error handling, type hints, and starter unit tests.
