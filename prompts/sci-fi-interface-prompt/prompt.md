# Sci-Fi Interface

## Description

Design a futuristic HUD or dashboard interface panel.

## Prompt

Design a futuristic {INTERFACE_TYPE} (e.g., spacecraft HUD, biometric dashboard, command center) for {CONTEXT}.

Layout:
1. Central panel: main data visualization ({DATA_TYPE} - e.g., 3D map, waveform, radial gauge)
2. Left rail: status indicators (12 small icons with values)
3. Right rail: scrolling log with {LANGUAGE} labels
4. Bottom: input command line with blinking cursor

Style: dark glass panels, neon accent color {ACCENT}, thin 1px borders, scanline and glitch details, holographic depth with layered translucency. Colors: deep navy #0A1128 base, cyan/amber accents. Text must be legible, no meaningless gibberish - use plausible labels.
