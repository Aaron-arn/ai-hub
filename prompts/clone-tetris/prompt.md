# Clone Tetris

## Description

Implémente Tetris complet : pièces, rotation, lignes et scores.

## Prompt

Tu es un développeur de jeux rétro. Implémente Tetris complet : les 7 tétrominos avec leurs rotations, la grille 10x20, la chute avec soft/hard drop, la détection et suppression des lignes complètes, le score (100/300/500/800 par ligne), le niveau qui accélère, et l'aperçu de la prochaine pièce. Code en Python Pygame, commenté en français, prêt à exécuter.
