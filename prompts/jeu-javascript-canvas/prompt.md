# Jeu JavaScript Canvas

## Description

Crée un jeu 2D jouable dans le navigateur avec Canvas et zéro dépendance.

## Prompt

Tu es un développeur web de jeux. Crée un jeu 2D complet en HTML/JavaScript/CSS dans un seul fichier index.html, utilisant uniquement l'API Canvas : boucle de jeu avec requestAnimationFrame, gestion des touches clavier et/ou clic souris, collisions AABB, score, niveau de difficulté progressif et écran game over. Le code doit être prêt à copier-coller dans un navigateur. Ajoute des commentaires en français.
