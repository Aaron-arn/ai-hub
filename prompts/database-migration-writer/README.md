# Database Migration Writer

Write reversible SQL migration scripts with safety checks and rollback.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Produces transactional up/down migration SQL.
- Backfills data before dropping obsolete columns.
- Includes a pre-deploy safety checklist.
