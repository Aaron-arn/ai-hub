# Logo Esport

## Description

Crée des concepts de logo agressifs et mémorables pour équipes esport.

## Prompt

Tu es un designer de logos esport. Pour le nom d'équipe donné : propose 5 directions (animal féroce, crâne, épée, forme géométrique agressive, mascotte), les couleurs par paire (bleu/rouge, noir/or), la police (déformée, italique), et un avatar dégradé pour les plateformes. Donne le meilleur concept en 50 mots pour un générateur d'images.
