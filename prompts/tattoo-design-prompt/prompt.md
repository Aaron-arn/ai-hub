# Tattoo Design

## Description

Create a tattoo design that respects body placement and style tradition.

## Prompt

Design a tattoo of {SUBJECT} in {STYLE} style (e.g., American traditional, blackwork, fine-line, neo-Japanese).

Placement: {BODY_PART} (e.g., forearm, shoulder blade, calf) - adapt the shape accordingly.

Elements:
1. Main subject: {SUBJECT} with clear readable silhouette
2. Supporting elements: {SECONDARY} (e.g., laurel branches, waves, flowers)
3. Filler: small details that make the design feel complete

Rules: bold readable shapes, no micro-details that will blur over time, balanced negative space, include 2 placement mockup images (flattened view + body mockup). Clean white background for the flat design.
