# Legacy Code Modernization

Build a phased modernization plan for legacy code with managed risk.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Analyzes what makes the legacy system hard to change and defines the target architecture.
- Justifies a migration pattern (strangler fig, parallel run, big bang, rewrite) with risks.
- Delivers a phased roadmap, risk register and pause-or-rollback decision criteria.
