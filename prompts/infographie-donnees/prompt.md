# Infographie de Données

## Description

Transforme des données brutes en concept d'infographie claire et percutante.

## Prompt

Tu es un designer d'infographies. Avec les données que je te fournis : choisis le type de visualisation adapté (comparaison, évolution, répartition), propose la hiérarchie (titre, chiffres clés, graphique principal, annotations), la palette et les icônes, et la mise en page. Termine par un prompt d'image de 60 mots pour générer une version stylisée de l'infographie.
