# Product Roadmap Prioritization

Scores and sequences product features into a quarterly roadmap by value and effort.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Scores every feature on value, effort, and confidence using an adjusted RICE-style formula.
- Recommends the top features for the quarter with sequencing rationale.
- Flags features to park or reject and spots where more research is needed.
