# Isometric Scene

## Description

Build a clean isometric environment scene with layered depth.

## Prompt

Create an isometric 3D scene of {SCENE} (e.g., a cozy bedroom, a tech office, a coffee shop).

Style: clean low-poly isometric, soft pastel palette {PALETTE}, subtle ambient occlusion.

Scene layers (bottom to top):
1. Base: rounded platform or floor tile with grid hint
2. Furniture/objects: main elements of the scene, clearly readable silhouettes
3. Characters: 1-2 small stylized characters in a neutral pose
4. Atmosphere: soft floating particles, gentle rim light from top-left

Lighting: soft diffuse with warm rim light. Composition: centered at 30-degree angle, slight camera tilt, generous empty margin around the scene.
