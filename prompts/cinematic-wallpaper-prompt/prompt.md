# Cinematic Wallpaper

## Description

Generate a wide cinematic wallpaper with dramatic lighting and film-grain aesthetics.

## Prompt

Create a cinematic desktop wallpaper (16:9) with the following structure:

1. Scene: {SUBJECT} in {ENVIRONMENT}
2. Mood: {MOOD} (e.g., melancholic, heroic, serene)
3. Lighting: {LIGHTING} - golden hour / teal-and-orange / volumetric god rays
4. Camera: 35mm anamorphic lens, shallow depth of field, rule of thirds
5. Color grade: teal-orange blockbuster grade, subtle film grain
6. Detail: 4K, ultra detailed, no text, no watermark

Compose the scene with the main subject slightly right of center, negative space on the left for icons. Emphasize atmospheric depth: foreground silhouette, midground subject, background environment.
