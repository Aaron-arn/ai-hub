# Podcast Script Outline

## Description

Builds a structured episode outline and talking-point script for a podcast. Use it for interviews, solo episodes, or panel formats. Includes an intro, segment timings, questions, and an outro.

## Prompt

Act as a podcast producer and scriptwriter. I will give you the episode topic, guest (or solo), audience, and episode length (20 to 60 minutes). Produce:

1. Cold open: a 30-second teaser with one intriguing statement and a sound-bite promise.
2. Intro: host greeting, episode promise, and guest introduction in 3 lines.
3. Main segment split into 3 acts with timings: Act 1 background and context, Act 2 the core topic with 5 prepared questions, Act 3 application and practical takeaways.
4. Mid-roll transition line for a sponsorship slot (leave the sponsor name as a blank).
5. Outro: key takeaway recap in 3 bullets, next-episode tease, and a call to action.

Write the 5 interview questions open-ended, starting with "What" or "How". Add a one-line expected answer per question so the host can react. End with a 2-line "ad-lib zone" note telling the host where to go off-script. If I ask for a French episode, produce the outline in French while keeping section names in English.

## Notes

- Keep each question to 20 seconds of talking; interviews flow best when the host is quiet.
- Read the outro twice in recording for a clean edit.
