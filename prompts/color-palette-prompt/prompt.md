# Color Palette

## Description

Generate a harmonious color palette with swatches and usage guidance.

## Prompt

Generate a color palette for {CONTEXT} (e.g., a meditation app, a streetwear brand).

Mood: {MOOD}
Base hue: {HUE} (with a twist: suggest 3 variations of the scheme)

Output as a labeled grid:
1. 5 swatches, each with hex code
2. Name for each color (e.g., "Dusk", "Paper")
3. Recommended usage (background, text, primary CTA, accent, border)
4. One 60/30/10 example: a small UI card mockup applying the palette

Ensure WCAG AA contrast for text colors. Flat design, minimal, swatches at exact hex colors.
