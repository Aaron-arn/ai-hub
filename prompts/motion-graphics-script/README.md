# Motion Graphics Script

Creates a frame-by-frame motion graphics script with timing, motion notes, and style direction.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Builds a scene table with time, visuals, motion, and sound.
- Maps keyframes per scene for easy animation.
- Includes a 20-word voice-over line for the final video.
