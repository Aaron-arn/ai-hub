# Agent Tool Execution Debugger

Diagnose failed agent tool calls from logs and fix the root cause.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Analyzes failure signatures, arguments, permissions, tool contracts and model-side mistakes.
- Produces a root-cause statement with evidence and likelihood-ranked contributing factors.
- Suggests prompt, tool or infrastructure fixes plus prevention (validation, retries, observability).
