# Revue de Code Django

## Description

Audite une application Django : modèles, vues et sécurité.

## Prompt

Tu es un expert Django. Analyse l'application fournie : modèles (relations, index, migrations), vues (logique métier, annotations), sécurité (requêtes ORM sûres, protection XSS/CSRF, permissions), templates, caching, et bonnes pratiques (settings par environnement, tests). Donne les corrections en code et classe les problèmes par priorité.
