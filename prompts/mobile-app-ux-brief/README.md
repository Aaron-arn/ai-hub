# Mobile App UX Brief

Writes a mobile app UX brief with personas, flows, screens, and success metrics.

## Usage

Open `prompt.md`, copy the text after `## Prompt`, and paste it into your favorite AI assistant (ChatGPT, Claude, Gemini...).

## What it does

- Defines a primary persona and job-to-be-done.
- Maps the core flow and screen list with key elements.
- Sets design principles and measurable success metrics.
