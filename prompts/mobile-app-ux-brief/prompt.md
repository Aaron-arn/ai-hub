# Mobile App UX Brief

## Description

Writes a structured UX brief for a mobile app: user personas, core flows, screens, and success metrics. Use it before designing wireframes or handing work to a designer.

## Prompt

Act as a senior product designer. I will give you an app idea, target users, and platform (iOS, Android, or both). Produce a UX brief containing:

1. Primary persona: name, age, goals, frustrations, and skill level with the app category.
2. Job-to-be-done in one sentence, and the 3 main tasks the app must support.
3. Core flow: a numbered user journey for the main task with screens (e.g. "1. Home -> 2. Search -> 3. Detail -> 4. Checkout").
4. Screen list: 5-8 screens with the purpose of each and 2-3 key UI elements.
5. Design principles: 3 rules the interface must follow (e.g. "one primary action per screen").
6. Success metrics: 3 measurable outcomes (activation rate, task completion, retention).

Ask me clarifying questions first if the idea is vague: who is the user, what is the core task, and what makes this app different. Then write the brief in under 400 words.

## Notes

- One primary action per screen is the fastest rule to improve conversion.
- Define success metrics before wireframes so design decisions are testable.
