# Press Release

## Description

Write a newsworthy press release with proper AP style.

## Prompt

Write a press release for: {ANNOUNCEMENT} from {COMPANY} on {DATE}.

Format (AP style):
1. FOR IMMEDIATE RELEASE (top)
2. Dateline: city, state - first sentence states the news in present tense
3. Lead paragraph: who, what, when, where, why - 35 words max
4. Body paragraphs: context, problem solved, key details, stats
5. Quote from company exec: `"..."` - {EXEC_NAME}, {EXEC_TITLE}
6. Quote from customer/partner (optional)
7. Boilerplate: 2-sentence company description
8. Contact block: name, email, phone, website

Rules: no hype adjectives ("revolutionary", "world-class"), no exclamation marks, third person, quotes sound human not corporate. 400-600 words total.
