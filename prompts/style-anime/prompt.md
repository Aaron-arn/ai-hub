# Style Anime

## Description

Génère des illustrations anime avec personnages et scènes expressives.

## Prompt

En tant qu'illustrateur anime, crée l'illustration demandée : style (Shonen, slice of life, mecha), personnage avec coiffure, tenue et expression, arrière-plan (école, ville, champ de bataille), effets (lignes de vitesse, particules, éclats). Livre une description de 80 mots avec 'anime style', 'cel shading'.
