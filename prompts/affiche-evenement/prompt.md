# Affiche d'Événement

## Description

Conçois une affiche percutante pour tout type d'événement.

## Prompt

En tant que graphiste, crée le concept d'affiche pour l'événement que je décris : idée visuelle centrale, style (typographique, illustration, photo), hiérarchie des informations (titre, date, lieu, billetterie), palette, et format. Donne une description de 70 mots pour un générateur d'images.
