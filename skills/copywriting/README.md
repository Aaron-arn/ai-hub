# Skill: Copywriting

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for writing persuasive and readable copy:

- defining the goal and audience before writing
- clarity and concision rules
- persuasion techniques and calls to action
- tone and self-review checklist

## Usage

Provide this skill's instructions to an AI agent before asking it to write landing pages, emails, product descriptions or marketing copy, for example by injecting `skill.md` into its system prompt.
