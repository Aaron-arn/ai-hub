# Skill: CLI Mastery

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for working efficiently in the terminal:

- reading help and discovering flags
- pipes, redirection and composition
- output inspection and grep
- safe scripting habits

## Usage

Provide this skill's instructions to an AI agent before asking it to run commands or write shell scripts, for example by injecting `skill.md` into its system prompt.
