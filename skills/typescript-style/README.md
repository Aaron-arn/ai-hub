# Skill: TypeScript Style

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for using TypeScript effectively:

- strictness and configuration
- type modeling and design
- generics and narrowing
- project structure and migration

## Usage

Provide this skill's instructions to an AI agent before asking it to write or review TypeScript code, for example by injecting `skill.md` into its system prompt.
