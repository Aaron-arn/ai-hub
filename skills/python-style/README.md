# Skill: Python Style

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for writing idiomatic, maintainable Python:

- typing and function design
- idioms and stdlib usage
- error handling and context managers
- project structure and packaging

## Usage

Provide this skill's instructions to an AI agent before asking it to write or review Python code, for example by injecting `skill.md` into its system prompt.
