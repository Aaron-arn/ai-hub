# Skill: Data Visualization

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for creating honest, readable charts:

- choosing the right chart type
- axes, scales and encodings
- color and labeling
- avoiding misleading visuals

## Usage

Provide this skill's instructions to an AI agent before asking it to create or review a chart, for example by injecting `skill.md` into its system prompt.
