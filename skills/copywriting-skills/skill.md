# Copywriting

## When to use
Apply when writing anything that asks for attention or action: landing pages, emails, ads, onboarding, error messages.

## Foundations
- One reader, one action, one message per piece. Clarity beats cleverness.
- Benefits over features: convert "128-bit encryption" into "your data stays private".
- Specific beats vague: "3x faster builds" beats "very fast".
- Write for scanning: short sentences, short paragraphs, meaningful headings.

## Formula frameworks
- AIDA: Attention -> Interest -> Desire -> Action.
- PAS: Problem -> Agitate -> Solve.
- 4U headline test: Useful, Urgent, Unique, Ultra-specific.

## Headlines
- Promise the outcome, not the activity: "Ship faster" not "Our new CI pipeline".
- Use numbers and timeframes; avoid hype words (revolutionary, game-changing).
- Test variations: outcome, question, negative framing, curiosity gap.

## Body copy
- Open with the strongest benefit; support with proof (numbers, testimonials, details).
- Address objections explicitly before the ask.
- Every paragraph earns the next one; cut any sentence that doesn't drive action.

## Calls to action
- One CTA per page; action verb + benefit ("Start free trial", "Get the checklist").
- Reduce friction: state cost, time commitment, risk-reversal ("cancel anytime").

## Tone
- Match the audience's vocabulary, not the brand's internal jargon.
- Be specific about the reader: "If you're a solo founder..." is permission to care.
- Revise out loud; clunky rhythms get rewritten.
- Editing pass: remove every filler word ("very", "really", "just", "basically").

## Error messages and microcopy
- What happened (plain language) + why it matters + what to do next, in that order.
- Never blame the user ("You entered an invalid email" -> "That email format looks off").
