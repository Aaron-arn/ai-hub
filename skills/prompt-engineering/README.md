# Skill: Prompt Engineering

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for crafting effective LLM prompts:

- role and goal definition
- structure and constraints
- context and few-shot examples
- evaluation and iteration

## Usage

Provide this skill's instructions to an AI agent before asking it to design prompts, improve an existing prompt, or structure an LLM-powered interaction, for example by injecting `skill.md` into its system prompt.
