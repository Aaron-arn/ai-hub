# Skill: Go Style

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for writing idiomatic Go:

- formatting and naming conventions
- packages and interfaces
- error handling
- concurrency and context

## Usage

Provide this skill's instructions to an AI agent before asking it to write or review Go code, for example by injecting `skill.md` into its system prompt.
