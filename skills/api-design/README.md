# Skill: API Design

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for designing consistent, evolvable APIs:

- resource modeling and REST conventions
- naming and HTTP semantics
- pagination, filtering and errors
- versioning and backward compatibility

## Usage

Provide this skill's instructions to an AI agent before asking it to design or review an API, for example by injecting `skill.md` into its system prompt.
