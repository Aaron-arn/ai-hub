# Skill: Backup and Recovery

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for protecting data and planning recovery:

- inventorying and classifying data by value
- defining RPO and RTO targets
- backup design and rotation
- rehearsed restores and drills
- a documented disaster recovery plan

## Usage

Provide this skill's instructions to an AI agent before asking it to design a backup strategy, write a recovery runbook or review disaster readiness, for example by injecting `skill.md` into its system prompt.
