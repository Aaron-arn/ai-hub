# Skill: Code Migration

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for migrating and porting code safely:

- understanding and inventorying the source first
- planning small, reversible increments
- porting intent and idioms, not syntax
- preserving behavior and verifying with tests

## Usage

Provide this skill's instructions to an AI agent before asking it to port code to another language or framework, or to plan a migration, for example by injecting `skill.md` into its system prompt.
