# Skill: Microservices

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for designing and operating microservices:

- deciding when microservices are actually justified
- defining service boundaries and data ownership
- communication, timeouts and circuit breakers
- consistency patterns for distributed data
- operational standards and service governance

## Usage

Provide this skill's instructions to an AI agent before asking it to design a service split, review an architecture or plan an extraction, for example by injecting `skill.md` into its system prompt.
