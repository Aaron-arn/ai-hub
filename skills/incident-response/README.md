# Skill: Incident Response

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for responding to production incidents:

- restoring service before deep analysis
- systematic investigation under pressure
- mitigation and rollback discipline
- communication cadence and channels
- blameless postmortems with action items

## Usage

Provide this skill's instructions to an AI agent before asking it to help with an incident, draft a status update or write a postmortem, for example by injecting `skill.md` into its system prompt.
