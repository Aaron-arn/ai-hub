# Skill: GraphQL

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for working with GraphQL APIs:

- schema design around client use cases
- query, mutation and pagination conventions
- performance protection against N+1 and deep queries
- resolver-level authorization and safety
- consumption patterns and schema tooling

## Usage

Provide this skill's instructions to an AI agent before asking it to design a schema, write resolvers or consume a GraphQL API, for example by injecting `skill.md` into its system prompt.
