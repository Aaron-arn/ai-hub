# Skill: Error Handling

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for handling failures robustly:

- designing for failure from the start
- validating input at the boundary
- typing, propagating and recovering from errors
- reporting failures clearly and testing error paths

## Usage

Provide this skill's instructions to an AI agent before asking it to write or review error handling, for example by injecting `skill.md` into its system prompt.
