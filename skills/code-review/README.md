# Skill: Code Review

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides a structured review checklist and feedback style for reviewing code changes:

- correctness
- security
- performance
- readability and maintainability
- tests

## Usage

Provide this skill's instructions to an AI agent before asking it to review a change, for example by injecting `skill.md` into its system prompt.
