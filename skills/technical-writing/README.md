# Skill: Technical Writing

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for writing accurate, followable technical documentation:

- defining the reader and prerequisites
- document and tutorial structure
- precision rules for steps, commands and examples
- formatting and maintenance practices

## Usage

Provide this skill's instructions to an AI agent before asking it to write or review documentation, guides or tutorials, for example by injecting `skill.md` into its system prompt.
