# Skill: Code Management

Load `skill.md` into the agent's context to enable this skill.

## What it does

Guides the agent through clean code management practices:

- version control workflow (git)
- commit conventions
- branching strategy
- dependency hygiene
- project structure and organization

## Usage

Provide this skill's instructions to an AI agent before it works on a codebase, for example by injecting `skill.md` into its system prompt.
