# Skill: Monitoring

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for monitoring production systems:

- measuring user-facing health and SLOs
- defining meaningful metrics
- writing alerts with runbooks and owners
- building useful dashboards
- synthetic checks and alert maintenance

## Usage

Provide this skill's instructions to an AI agent before asking it to design monitoring, write alerts or review dashboards, for example by injecting `skill.md` into its system prompt.
