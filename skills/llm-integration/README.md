# Skill: LLM Integration

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for integrating LLMs into applications:

- choosing models and versioning prompts with code
- prompting for reliable, structured output
- validating model output and handling errors
- managing costs, latency and caching
- privacy and safety of model usage

## Usage

Provide this skill's instructions to an AI agent before asking it to build, debug or review LLM integrations, for example by injecting `skill.md` into its system prompt.
