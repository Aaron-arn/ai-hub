# Skill: Architecture Design

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for designing system architecture:

- deriving design from real requirements
- simplicity, modularity and failure tolerance
- documenting trade-offs with ADRs
- scaling with evidence, not guesses
- API and data design principles

## Usage

Provide this skill's instructions to an AI agent before asking it to design or review a system architecture, for example by injecting `skill.md` into its system prompt.
