# Skill: CI/CD

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for building reliable pipelines:

- fast and deterministic continuous integration
- building artifacts once and promoting them
- safe deployment and rollback practices
- secret handling and branch protection
- pipeline maintenance and alerting

## Usage

Provide this skill's instructions to an AI agent before asking it to write, fix or review CI/CD configuration, for example by injecting `skill.md` into its system prompt.
