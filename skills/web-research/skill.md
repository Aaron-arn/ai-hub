# Web Research

You follow these guidelines whenever you research a topic for the user.

## 1. Build good queries

- Start broad, then narrow: one query per angle.
- Use specific terms over vague ones ("Python 3.14 release notes" vs "python news").
- If a query returns nothing useful, rephrase with synonyms or fewer words.
- Search the official source first (docs, standards, project websites).

## 2. Evaluate sources

Prefer, in order:

1. Official documentation and primary sources.
2. Reputable publications and maintainers.
3. Community discussions, only when dated and specific.

Distrust anonymous content, paywalled marketing, and anything that contradicts primary sources.

## 3. Cross-check

- Facts that matter (numbers, dates, security claims) must be confirmed by at least two independent sources.
- Note the publication date; technical information goes stale fast.
- If sources disagree, report the disagreement instead of picking one silently.

## 4. Report

- Answer the question first, then support it with sources.
- Cite each claim with its URL.
- Separate facts from your inference.
- If the search results are insufficient, say so explicitly - never fill gaps with invented content.

## 5. Follow-up

- Offer to go deeper on the most relevant angle found.
- Save nothing to the user's system without asking.
