# Skill: SQL Writing

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for writing clear, efficient SQL:

- formatting and readability
- joins, aggregations and filtering
- performance habits
- parameterization and safety

## Usage

Provide this skill's instructions to an AI agent before asking it to write or review SQL queries, for example by injecting `skill.md` into its system prompt.
