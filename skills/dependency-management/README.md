# Skill: Dependency Management

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for managing dependencies responsibly:

- evaluating before adding a dependency
- pinning versions and committing lockfiles
- upgrading in small, tested steps
- vulnerability scanning and remediation
- pruning unused and duplicated packages

## Usage

Provide this skill's instructions to an AI agent before asking it to add, upgrade, audit or remove dependencies, for example by injecting `skill.md` into its system prompt.
