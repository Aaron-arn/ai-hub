# Skill: Rust Style

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for writing safe, idiomatic Rust:

- ownership, borrowing and lifetimes
- error handling and Result/Option
- traits and generics
- concurrency and unsafe discipline

## Usage

Provide this skill's instructions to an AI agent before asking it to write or review Rust code, for example by injecting `skill.md` into its system prompt.
