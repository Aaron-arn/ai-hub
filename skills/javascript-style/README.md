# Skill: JavaScript Style

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for writing clean, modern JavaScript:

- ES2020+ features and idioms
- functions, modules and naming
- async handling and error propagation
- testing and tooling

## Usage

Provide this skill's instructions to an AI agent before asking it to write or review JavaScript code, for example by injecting `skill.md` into its system prompt.
