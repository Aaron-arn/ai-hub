# Skill: Agent Development

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for building reliable AI agents:

- defining narrow, well-scoped tools
- loop limits, stopping conditions and progress checks
- explicit memory design with bounds
- safety, sandboxing and human oversight
- evaluation and regression testing of agent behavior

## Usage

Provide this skill's instructions to an AI agent before asking it to design, build or review an AI agent, for example by injecting `skill.md` into its system prompt.
