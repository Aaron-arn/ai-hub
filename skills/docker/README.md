# Skill: Docker

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for working with Docker effectively:

- writing efficient, cache-friendly Dockerfiles
- images, layers and size
- containers, volumes and networking
- security and debugging

## Usage

Provide this skill's instructions to an AI agent before asking it to write a Dockerfile, debug a container, or review a container setup, for example by injecting `skill.md` into its system prompt.
