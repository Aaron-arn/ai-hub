# Skill: Database Design

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for designing relational database schemas:

- normalization and denormalization trade-offs
- data types, constraints and naming
- index design
- migrations and schema evolution

## Usage

Provide this skill's instructions to an AI agent before asking it to design a schema, write a migration, or review an existing database model, for example by injecting `skill.md` into its system prompt.
