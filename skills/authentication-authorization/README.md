# Skill: Authentication and Authorization

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for implementing identity safely:

- using proven libraries and standards, never custom crypto
- password storage, MFA and rate limiting
- token and session management
- resource-level authorization and least privilege
- auth hardening, logging and testing

## Usage

Provide this skill's instructions to an AI agent before asking it to implement or review authentication or authorization, for example by injecting `skill.md` into its system prompt.
