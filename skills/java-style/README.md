# Skill: Java Style

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for writing clean, modern Java:

- language level and structure
- naming and API design
- error handling and null safety
- testing and build hygiene

## Usage

Provide this skill's instructions to an AI agent before asking it to write or review Java code, for example by injecting `skill.md` into its system prompt.
