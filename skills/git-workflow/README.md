# Skill: Git Workflow

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for working with git in a clean, reviewable way:

- branching strategy
- commit hygiene and messages
- rebasing and history cleanup
- pull request workflow
- conflict resolution and reverts

## Usage

Provide this skill's instructions to an AI agent before asking it to set up a branch, write commits, or prepare a pull request, for example by injecting `skill.md` into its system prompt.
