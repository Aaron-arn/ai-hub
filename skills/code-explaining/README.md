# Skill: Code Explaining

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for explaining code to humans clearly:

- adapting depth to the audience's level
- explaining intent and architecture before lines
- being concrete with examples and references
- structuring explanations and verifying accuracy

## Usage

Provide this skill's instructions to an AI agent before asking it to explain a codebase, walk through an algorithm or help someone understand a change, for example by injecting `skill.md` into its system prompt.
