# Skill: Communication

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for effective written communication:

- clarity and directness rules
- giving context to the reader
- respectful tone in disagreements
- asking and answering well
- async and remote communication practices

## Usage

Provide this skill's instructions to an AI agent before asking it to draft messages, updates, reviews or responses, for example by injecting `skill.md` into its system prompt.
