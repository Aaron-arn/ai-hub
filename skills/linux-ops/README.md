# Skill: Linux Ops

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for safe Linux administration:

- processes, resources and troubleshooting
- filesystem permissions and ownership
- services and systemd
- security and change discipline

## Usage

Provide this skill's instructions to an AI agent before asking it to administer a Linux machine, debug a service, or write operational scripts, for example by injecting `skill.md` into its system prompt.
