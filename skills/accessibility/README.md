# Skill: Accessibility

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for building accessible products:

- semantic HTML and ARIA
- keyboard support and focus management
- screen reader and testing practices
- content and color accessibility

## Usage

Provide this skill's instructions to an AI agent before asking it to audit or build accessible interfaces, for example by injecting `skill.md` into its system prompt.
