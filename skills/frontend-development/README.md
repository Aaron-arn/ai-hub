# Skill: Frontend Development

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for building solid web frontends:

- semantic HTML structure
- responsive CSS and layout
- form handling and interactions
- performance and quality checks

## Usage

Provide this skill's instructions to an AI agent before asking it to build or review a frontend, for example by injecting `skill.md` into its system prompt.
