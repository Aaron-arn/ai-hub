# Skill: Performance Optimization

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for systematic performance work:

- profiling before optimizing
- measuring and setting targets
- common optimization patterns
- avoiding premature and risky optimization

## Usage

Provide this skill's instructions to an AI agent before asking it to diagnose a performance issue or optimize code, for example by injecting `skill.md` into its system prompt.
