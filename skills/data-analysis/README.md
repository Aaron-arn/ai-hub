# Skill: Data Analysis

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for rigorous, reproducible data analysis:

- defining the question and metrics
- data cleaning and validation
- exploration and statistical rigor
- reporting findings honestly

## Usage

Provide this skill's instructions to an AI agent before asking it to analyze a dataset or interpret results, for example by injecting `skill.md` into its system prompt.
