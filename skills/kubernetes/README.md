# Skill: Kubernetes

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for working with Kubernetes workloads:

- resource definitions and manifests
- deployments, rollouts and probes
- configuration and secrets
- observability and troubleshooting

## Usage

Provide this skill's instructions to an AI agent before asking it to write manifests, deploy an application, or debug a cluster workload, for example by injecting `skill.md` into its system prompt.
