# Skill: Release Management

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for shipping releases users can trust:

- semantic versioning rules
- changelog writing and maintenance
- a repeatable release process
- phased rollout and rollback readiness
- release communication and follow-up

## Usage

Provide this skill's instructions to an AI agent before asking it to plan a release, write a changelog or review versioning practices, for example by injecting `skill.md` into its system prompt.
