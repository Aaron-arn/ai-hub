# Skill: Logging and Observability

Load `skill.md` into the agent's context to enable this skill.

## What it does

Provides guidelines for making systems inspectable in production:

- deciding what to log and at which level
- structured logging and stable field names
- request correlation across services
- security and hygiene of log content
- distributed tracing practices

## Usage

Provide this skill's instructions to an AI agent before asking it to add logging, instrumentation or tracing to a system, for example by injecting `skill.md` into its system prompt.
