# URL Tools

Parse URLs, encode/decode URL components and query strings.

## Usage

```bash
python main.py parse "https://example.com/path?a=1&b=2#frag"
python main.py encode "a b&c=d"
python main.py decode "a%20b%26c%3Dd"
python main.py query "a=1&b=2&b=3"
```

## Permissions

- No permissions required
