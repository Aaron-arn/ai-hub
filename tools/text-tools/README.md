# Text Tools

Count, transform and manipulate text.

## Usage

```bash
python main.py count "hello world"
python main.py slug "Hello World!"
python main.py upper "hello"
python main.py lower "HELLO"
python main.py title "hello world"
python main.py replace "hello world" "world" "aihub"
```

## Output

JSON object with the result.

## Permissions

- No permissions required
