# Unit Converter

Convert between length, weight, temperature and volume units. Uses only the Python standard library.

## Usage

```bash
python main.py 100 km mi
python main.py 32 f c
python main.py 2.5 kg lb
```

## Output

The converted value, printed to stdout.

## Security

- Pure computation, no I/O
- No network, no filesystem, no shell access
