# Math Tools

Number theory helpers: gcd, lcm, primes, factorial, fibonacci. Uses only the Python standard library.

## Usage

```bash
python main.py gcd 12 18
python main.py primes 30
python main.py factor 84
python main.py fibonacci 10
```

## Output

The numeric result or list of numbers, printed to stdout.

## Security

- Pure computation, no I/O
- No network, no filesystem, no shell access
