# Hash Tools

Compute common digests and base64 encodings.

## Usage

```bash
python main.py md5 "hello"
python main.py sha256 "hello"
python main.py sha512 "hello"
python main.py base64-encode "hello world"
python main.py base64-decode "aGVsbG8="
```

## Output

JSON object with the digest or encoded value.

## Permissions

- No permissions required
